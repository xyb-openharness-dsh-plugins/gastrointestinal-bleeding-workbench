# 差异化矩阵（DIFF-MATRIX）· 消化道出血工作台 CX-001

- 对比基准（本地只读对照，不写链接）：`traps-workbench`（0.2.1，家族非肿瘤线结构底本）、`cervical-workbench`（移植样板）、`breast-cancer-workbench`（成熟基准 v0.4）。
- 口径：只比结构、元素体系与命名，不比病种语义；一级重名率 = 一级导航同名条目 ÷ 本仓一级条目。

## 1. 一级导航对照（实测）

| 本仓一级 | 结构来源 | 基准同类项 | 是否同名 |
| --- | --- | --- | --- |
| 求助与记录 | 本病种首发场景（先求助、后记录） | 病程与诊断过程 / 记录 | 否（语义从"记录病程"改为"求助优先"） |
| 我的记录 | 家族记录区 | 记录治疗 / 用药 / 指标检测（拆多页） | 否（本病种把八类合并为一页可筛） |
| 临床研究 | 35 号四段链路 | 临床研究 | **是**（家族标准入口名） |
| 疾病概要 | 36 号整页概要 | 疾病概要 | **是**（家族标准件，id 必须四段） |
| 设置 | 家族设置 | 设置 | **是**（家族标准件） |

- 一级条目数：5；同名 3 条（其中 2 条为 36 号/设置标准件，1 条为 35 号标准入口名）→ 重名率 **3/5 = 60% ≤ 70%**，通过。
- 说明：家族标准件同名是规范要求，不是复制；差异体现在二级结构与病种内容。

## 2. 二级/功能线对照

| 功能线 | 基准做法 | 本仓做法 | 差异理由 |
| --- | --- | --- | --- |
| 首屏 | 顶部常驻摘要/趋势 | **紧急求助条置顶 + 记录可整段跳过** | 出血可能急症；不能让用户先填表 |
| 记录模型 | 按 Tab 拆（用药/指标/就诊…） | 八类 kind 同页切换（bleed/lab/treatment/question/hospital/report/doc/mind） | 单一记录源，减少跨页搬运；服务层同形落库 |
| 试验匹配 | 器官/表型 chips | 出血表现 + **抗栓药** chips（抗凝/抗血小板/NSAIDs） | 抗栓药是本类患者入排与风险语境的核心变量 |
| 疾病概要 | 36 号四段 | 36 号四段（definition/evidence/landscape/trend），来源状态逐条对齐 USER-RESEARCH | 标准件；内容按本病重写 |
| 指标 | 趋势图 + 指标卡 | 本阶段**不做趋势图**，只做化验原值记录 | 试点范围先保求助+交接；趋势线列为后续里程碑（如实记未实现） |
