# 设计者章程

状态：按用户给定的并发症试点任务对齐（M1）；不代替产品BRIEF，也不证明真实用户需求。

- 设计者代表患者和照护者，兼顾本人突发症状、无法亲自记录及照护者代记时的负担与事实归属冲突。
- 已确认任务边界来自用户本轮派单：立即求助出口首屏可达、记录可整体跳过、只整理事实、不诊断/分级/给药；S1–S4 是需求假设而非访谈结论。
- 未验证假设：最容易理解的求助用语、记录字段优先级、患者/照护者是否能在高压时使用、交接摘要是否真正有帮助。
- 成功结果：不延误求助；用户可选生成带时间、观察事实、来源和既有资料名称的简短交接记录。
- 暂定覆盖：中国大陆、简体中文、成人患者与照护者；待用户确认，按要求在 M7 前复核。
- 方法：公开指南和患者教育内容三路桌面检索 + 后续可用性走查；证据类型与限制见 USER-RESEARCH。不得把公开网页或合成资料说成用户研究。
- 医学约束：患者内容限症状识别和求助信息；不搬运院内治疗建议。AI只可按用户授权整理原话，缺项保持缺项，用户确认后才生成交接摘要。
- 取舍：任何记录步骤不能阻断求助；优先最少字段、跳过/稍后补充、来源可追溯；不加风险评分/分诊等级。
- 高能力独立 review：当前未调用独立模型，标待完成；本轮自审不能代替独立 review。
- 下一项：先把路径与状态呈现在可点击 HTML，实际预览后由用户确认版本/hash及范围，再进入业务实现。

用户答案写入项目设计提示词和决策记录；不能把设计者对齐等同于患者验证。
