# M2 视觉方向记录

- 目标情绪：沉着。急迫信息要一眼找到，页面整体不制造恐慌，也不让用户觉得必须填完资料才能求助。
- 主基因：瑞士平面/包豪斯（`taste` 的 `moods/09 清晰理性` 与 `code-genes/01 瑞士平面/包豪斯`）。
- 辅基因：克制的人文温度，仅用文字语气和宽松留白，不增加第二套装饰色/插画风格。
- 翻译参数：浅暖白底 `#f7f8fa`、纯白工作面、正文 `#1a1a1a`/辅助 `#4a4a4a`/弱提示 `#6b7280`；唯一功能强调色为高对比深朱红，用于急诊求助 CTA 与少数危险提示；1px 中性线、2px 圆角、无渐变/阴影；无衬线字体、左对齐、12列桌面栅格，窄窗单列；正文至少 16px、大字设置可放大至 20px。
- 组件气质：求助 CTA 是第一视线且常驻首屏；表单低压、可选；「未知/跳过」显式，空数据不渲染为阴性结果。
- 一句话自检：主基因清晰理性，辅基因是克制的照护温度；求助足够醒目，其他区域仍然安静易读。

状态：设计参数用于 M2 原型，尚无用户审美/可用性确认。
