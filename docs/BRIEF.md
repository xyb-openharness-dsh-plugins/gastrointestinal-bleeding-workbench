# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：中国大陆·简体中文·成人患者与照护者；首版范围待用户确认

场景：本人或照护者观察到疑似消化道出血表现时，优先寻求急救并可选整理事实与既有就诊资料；不诊断、不分级处置、不建议用药

核心流程：
1. 首屏呈现立即求助提示与紧急求助出口
2. 可直接结束记录并求助，或选择开始记录
3. 按发生时间、观察事实和既有就诊资料整理摘要
4. 预览并复制/导出交接摘要，不产生诊断或安全排除结论

完成结果：用户能跳过全部记录并直达紧急求助信息；若选择记录，可生成便于就诊交接的观察事实摘要

初始布局选择：business-first
