# UI / 信息架构重构 v0.3（2026-11-20）

## 1. 为什么改

- 用户反馈：与基准工作台（小粉宝 / 小胆宝）功能差距大、布局粗糙。
- 旧版 v0.2 只有「求助与记录 / 记录 / 临床 / 概要 / 设置」5 个一级页，缺少日常识别与预防、家庭监测、送医预案、指标与评分、复诊与后续、静脉曲张专项、专科资源等患者真正会用的线。

## 2. 新信息架构（9 个一级页 + 24 个子页）

按「预防 → 管理 → 处置 → 后续」组织：

| 一级页 | 子页 | 解决什么 |
| --- | --- | --- |
| 看板 | — | 第一屏：求助条 + 全程四步 + 关键数字 + 最近记录 |
| 识别与预防 | 日常识别 / 风险因素 / 预防清单 | 什么表现要马上求助；NSAIDs、抗栓药、Hp、肝硬化等风险；能提前做什么 |
| 家庭监测 | 今日记录 / 全部记录 / 症状与用药 / 家庭能测什么 | 八类记录、症状时间线、家庭测量边界 |
| 急诊与送医 | 现场处理 / 送医预案 / 交接摘要 | 现场安全动作、送医计划、就诊摘要 |
| 指标与评分 | 血红蛋白趋势 / 评分模型 / 报告对照 | Hb 趋势（单点不连线）、GBS/AIMS65/Rockall 变量对照、报告状态 |
| 复诊与后续 | 出院后计划 / 复查安排 / 问题清单 | 出院用药与复查、就诊时间线、要问医生的问题 |
| 静脉曲张专项 | 为什么会发生 / 监测与复查 / 脾切除后 | 脾静脉→胃底静脉曲张；胰腺癌胰体尾切除+脾切除术后专项 |
| 临床研究 | 建档与匹配 / 检索 / 收藏 | 35 号四段链路（沿用既有后端） |
| 专科与资源 | 专科中心 / 指南与来源 | 公开资料中的专科中心（非排序）与指南取得状态 |
